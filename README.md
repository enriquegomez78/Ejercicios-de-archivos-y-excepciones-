# Ejercicios-de-archivos-y-excepciones-

Este proyecto es una interfaz gráfica construida en JavaFX que integra tres herramientas de manejo de flujos de caracteres:

1. **Editor de Notas:** Permite crear, abrir y guardar archivos de texto usando `FileReader` y `FileWriter`.
2. **Estadísticas de Texto:** Analiza un archivo `.txt` y cuenta sus líneas, palabras y caracteres usando `BufferedReader`.
3. **Visualizador CSV:** Carga y muestra dinámicamente cualquier archivo `.csv` en un `TableView`, manejando errores de formato mediante bloques `try-catch`.

### Tecnologías usadas:
* Java
* JavaFX
* Manejo de Excepciones (`IOException`)
